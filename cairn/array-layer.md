# 阵列层（里程碑 2）

代码：`src/mmw60/frontend/array60.py`（`Array60`）、`src/mmw60/arraylink.py`（链路与训练预算）、`config.array_frontend`；示例 10；测试 `tests/test_array60.py`。

## 1. 用了 arraytx 的什么（用户 2026-11-14 定：只拿线性部分）

- vendor array_tx @ `286609e`（包名 `arraytx`）：只拷本库 import 到的 `geometry.py` 与 `beam.py`（`beam` 只依赖 `geometry`），原样；不放 `__init__.py`（上游的那份会 import `config` / `sim`，也就是整包），目录是 PEP 420 命名空间包，vendor 里每个文件仍是 verbatim。（2026-11-17 之前拷的是 @ `5815c5a` 的整包 135 个 `.py`，连它嵌套的 polartx、padpd；本库从没 import 过那些。这两个文件在两个 pin 之间没有变，指纹与示例 10 的输出不动。）
- 用到的只有：`ArrayGeometry`（单元位置、远场时延 τ_k(θ)、单元因子）、`beam.steering_phase_weights`、`beam.array_factor_cw`（测试里对照）、`beam.beam_response`（斜视）、`beam.beamwidth_3db_deg`。
- arraytx 是 28 GHz FR2 的库：没有 60 GHz 标准、没有码本、没有移相器量化、没有绝对功率和 SNR。这些都在本库补：
  - 移相器量化：以第一个单元为相位参考、四舍五入（坑：arraytx 的阵列以中心为原点，相位落在半步上，`np.round` 的取偶会让 2 bit 在 30° 处平白丢 3 dB，`tests/test_array60.py` 守着）；
  - 逐单元静态误差（arraytx 的默认 0.5 dB / 5°，它自己的取值）；
  - 训练码本（sin θ 均匀，±60°）；
  - EIRP 与接收阵列的 SNR 增益。
- 每个单元都是共享 `Frontend60` 的（铁律 2）：同一颗 PA、同一个接收面、同一个单元增益；两条拓扑用同一个 `Array60`。arraytx 的单元链（polar_tx 的 PA / DPD）不用。
- 一个单元（预设）就是原来的单元件链路：N = 1 时不加逐单元误差（单个单元的增益就是前端的工作点），示例 10 的 N = 1 行与单元件逐位一致，指纹不动。

## 2. 约定

- 发射：N 颗 PA 各输出 P_e，束向上场相干相加：EIRP = P_e + 20·log10|AF| + G_e(θ)。
- 接收：信号相干、N 路噪声不相干：G_rx = 20·log10|AF| − 10·log10 N + G_e(θ)（束向上 10·log10 N + G_e）。
- G_e(θ) = 前端的单元视轴增益（预设 0 dBi，即未指定）+ arraytx 的单元因子（场幅度；cos θ：45° 掉 3 dB，60° 掉 6 dB）。
- 量化损失（N = 64，扫描角平均）：4 / 3 / 2 / 1 bit 为 0.05 / 0.22 / 0.88 / 3.81 dB，sinc(π/2^B) 理论 0.06 / 0.22 / 0.91 / 3.92 dB。

## 3. EIRP 上限反过来让 PA 更线性（示例 10 §2）

前端预设每单元 7.1 dBm（从 Psat 回退 7.5 dB），单元 0 dBi：N 个单元的 EIRP = 7.1 + 20·log10 N，N > 44 时超过 FCC 15.255 的 40 dBm 平均值。

| N | 每单元输出 | 回退 | PA 单独 EVM | EIRP | 底板（B 11be 80M × 4） | 解码器上限 |
|---|---|---|---|---|---|---|
| 1 / 4 / 16 | 7.1 dBm | 7.50 dB | −21.1 dB | 7.1 / 19.2 / 31.0 dBm | −18.5 dB | MCS5 |
| 64 | 3.9 dBm | 10.74 dB | −27.8 dB | 40.0 dBm | −21.0 dB | **MCS6** |

N = 64 时三个方案的上限都升一档或两档（B 11ac 20M × 8：MCS4 → MCS6，A 11be 80M：MCS5 → MCS7；2026-11-15 门限加逼近之前 A 是 MCS6 → MCS7，A 的 N ≤ 16 那一档在 MCS6 门限区间的下沿，`comparison-table.md` §2b）。大阵列下，EIRP 上限而不是 PA 决定发射功率，PA 的工作点自动退到更线性的区域；效率代价（PA 直流功率随回退）2026-11-15 起算进功率列，见 §4b。

- 上限 MCS 的距离（15 dB/km）：N = 64 时 B 11be × 4 368 m、B 11ac × 8 346 m、A 493 m（门限加逼近之前 372 / 367 / 489）。

## 4b. 功率按 N 计（示例 10 §3c；用户 2026-11-15 定：PA × N + 每单元一个移相器）

每个链路方向：N_tx 颗 PA 按 EIRP 上限留下的每单元输出算直流（B 类规律），TX、RX 每个单元各一个移相器（`assumed.array_phase_shifter_power_mw` 15 mW，没有出处；N = 1 不计，那个单元就是前端自己），其余（频综、转换器、FFT、解码器，拓扑 A 的芯片 PA 与 DPD）与同台表的单元件口径相同，只算一份。LNA / 混频与单元件口径一样不计，1:N 分路 / N:1 合路的插损不另计。N = 1 那一行就是同台表自己的列（测试守着逐位相同）。

| 方案 | N = 1 | 4 | 16 | 64 | PA / 移相器 / 其余 mW（N = 64） |
|---|---|---|---|---|---|
| B 11be 80M × 4，pJ/bit（上限、Mb/s） | 361（MCS5、1153） | 659 | 1748 | 4279（MCS6、1297） | 3290 / 1920 / 341 |
| B 11ac 20M × 8 | 1039（MCS4、312） | 2141 | 6165 | 11669（MCS6、468） | 3290 / 1920 / 251 |
| A 11be 80M | 2418（MCS5、288） | 3611 | 7966 | 16186（MCS7、360） | 3290 / 1920 / 622 |

- **阵列买的是距离，不是速率**：N = 1 → 64 路径损耗多承受约 51 dB（§4），速率只在 N = 64 因 PA 回退变线性升一到两档；每比特能耗 B 11be × 4 涨到 ×1.8 / ×4.8 / ×11.9（N = 4 / 16 / 64）。
- **EIRP 上限之后，PA 的总直流不再涨**：N > 44 时每单元一起回退，单元输出 ∝ 1/N²；B 类规律下单颗 PA 的直流 ∝ √Pout ∝ 1/N，N 颗合起来是常数——N = 64 的 3290 mW 就是 N ≈ 44 时 44 × 74.6 mW。所以 N = 64 多出来的主要是移相器（128 个、1920 mW、占 35 %）；PAE 从 6.9 % 掉到 4.7 % 是同一件事的另一面。
- 移相器功耗是这一列最大的假设：0 / 30 mW 时 B 11be × 4 在 N = 16 是 1331 / 2164 pJ/bit（预设 1748），N = 64 是 2799 / 5760（预设 4279）。

## 5. 波束训练 SNR 预算（示例 10 §4；`assumed.array_training`）

802.11be 没有毫米波波束训练，按用户定的 MLO 触发：sub-7 链路排定扫描时刻（定时已知），每个扇区发一段升频后的基准 L-LTF（GI2 + 2 个符号）；先 TX 扫（对端一个单元接收），再 RX 扫（TX 已在选中的扇区）。接收端两符号逐音相干、跨音非相干估功率，取最大；选中扇区与最佳差 1 dB 以内算成功，要求 99 %。
平坦信道、已知定时下统计量有闭式（非中心卡方），`tests/test_array60.py` 拿逐音加噪声的蛮力仿真核对过（差 ≤ 0.03）。

|---|---|---|---|---|---|
| B 11be 80M × 4（996） | 4 / 16 / 64 | −9.5 / −10.5 / −10.0 dB | +3.1 / −2.5 / −8.8 dB | +21.6 / +16.0 / +10.6 dB | 55 / 221 / 883 µs |
| B 11ac 20M × 8（56） | 4 / 16 / 64 | −1.5 / −3.0 / −2.5 dB | −2.0 / −7.0 / −13.3 dB | +11.6 / +6.5 / +7.5 dB | 9 / 35 / 141 µs |
| A 11be 80M（996） | 4 / 16 / 64 | −9.5 / −10.5 / −10.0 dB | +3.1 / −2.5 / −8.8 dB | +20.8 / +15.3 / +12.2 dB | 218 / 874 / 3494 µs |

（2026-11-15 门限加逼近之前，后两列依次 +2.9 / −2.7 / −8.9、+21.4 / +15.8 / +10.5；−2.1 / −7.2 / −13.5、+11.8 / +6.7 / +6.6；+2.9 / −2.7 / −8.9、+23.3 / +17.7 / +12.4 dB。）

- **TX 扫是瓶颈**：对端只有一个单元，比数据链路少 10·log10 N 的接收增益。11be 基准的 996 个音给了约 −10 dB 的所需 SNR（比 MCS0 门限低 9 dB），N = 4 还够；N ≥ 16 起一段训练场的 TX 扫到不了 MCS0 的边，N = 64 差 8.8 dB；11ac 基准只有 56 个音，N = 4 就差了。重复训练场补上它的代价见 §5b。
- 上限 MCS 的范围内训练都够（+6.5 … +21.6 dB；门限加逼近之前 +6.6 … +23.3）：训练限制的是低速率的边缘覆盖，不是高速率。
- RX 扫总是够的（TX 已有全增益）。
- 升频让扫描变快：同一码本，扫描时长按 1/K 缩短（B 11be 80M × 4 是拓扑 A 的 1/4）。
- 灵敏度（N = 16，B 11be 80M × 4）：
  - 跨音相干累加少要 8 dB（−18.5 dB），TX 扫反而比 MCS0 远 5.5 dB，但它要求信道在整个带宽上平坦、定时准；
  - 码本过采样 ×2 多要 3.5 dB（−7.0 dB）、扫描时间翻倍：相邻扇区差不到 1 dB，更容易挑到差 1 dB 以上的；
  - 要求“必须选中最佳扇区”多要 11 dB（+0.5 dB）；
  - 移相器 2 / 1 bit 多要 0.5 / 2 dB；单元方向图换 isotropic、去掉单元误差几乎不动。

### 5b. 重复训练场补到 MCS0 的边（示例 10 §4b；用户 2026-11-15 定：重复 L-LTF、跨重复非相干累加；`assumed.array_training_repetition`）

每个扇区把训练场重复 R 次，跨重复按功率相加：统计量是 n R 个音的非中心卡方，不需要重复之间相位稳定。R 取 2 的幂，取 TX 扫的路径损耗不小于 MCS0 数据链路的最小 R。跨重复相干累加（每倍少要 3 dB）是乐观上界。

| 方案 | N | R（非相干） | 所需每音 SNR | TX 扫 − MCS0 | TX 扫时长 | R（相干） | TX 扫时长 |
|---|---|---|---|---|---|---|---|
| B 11be 80M × 4 | 4 / 16 / 64 | 1 / 4 / 64 | −9.5 / −13.5 / −19.5 dB | +3.1 / +0.5 / +0.7 dB | 28 µs / 437 µs / 27.9 ms | 1 / 2 / 8 | 28 µs / 219 µs / 3.5 ms |
| B 11ac 20M × 8 | 4 / 16 / 64 | 2 / 16 / 256 | −3.5 / −10.5 / −16.0 | +0.0 / +0.5 / +0.2 | 8 µs / 258 µs / 16.4 ms | 2 / 8 / 32 | 8 µs / 130 µs / 2.1 ms |
| A 11be 80M | 4 / 16 / 64 | 1 / 4 / 64 | −9.5 / −13.5 / −19.5 | +3.1 / +0.5 / +0.7 | 109 µs / 1.74 ms / 111 ms | 1 / 2 / 8 | 109 µs / 872 µs / 13.9 ms |

- 非相干累加每翻一倍省约 1.5 dB（996 个音时统计量近高斯，所需 SNR ∝ 1/√(nR)）：N = 64 差 8.8 dB 要 64 次；相干累加每倍 3 dB，8 次。
- **N = 16 可行，N = 64 贵**：N = 16 时 TX 扫 0.26–1.7 ms；N = 64 时 B 11be × 4 一个方向 27.9 ms、拓扑 A 111 ms（一个信标间隔约 100 ms），11ac 基准 16.4 ms（音少，要 256 次）。拓扑 A 慢 4 倍是因为它的符号没有升频。相干累加短 8 倍，但要求 R 段训练场之间相位稳定（CFO 残差、相噪），本库没建这一项，只当上界。
- 剩下的杠杆是分层训练（先少单元的宽波束、再在选中的扇区里细化，ROADMAP B）。

### 5c. 两级扫描（示例 10 §4c；用户 2026-11-16 定的优先级第 3 条）

第一级用前 m 个单元的子阵扫它的 m 个宽扇区（子阵按自己的单元数定工作点），第二级用整阵只扫第一级选中扇区里对着站点增益最高的 ⌈N/m⌉ 个窄扇区；对端都是一个单元接收，每一级各自重复到够得着目标为止（非相干累加），N = 64。

| 方案 | 目标 | 平扫 | m = 8：宽 / 窄 / 合计 | m = 16：宽 / 窄 / 合计 |
|---|---|---|---|---|
| B 11be 80M × 4 | MCS0 的边（144.3 dB） | 64 × 64 次，27.9 ms | 宽扫够不到（最多 132.9 dB）/ 8 × 64 次 3.5 ms / — | 够不到（139.6）/ 4 × 64 次 1.74 ms / — |
| B 11be 80M × 4 | 解码器上限（124.9 dB） | 64 × 1 次，442 µs | 8 × 16 次 871 µs / 55 µs / 926 µs | 16 × 1 次 110 µs / 28 µs / **138 µs** |
| B 11ac 20M × 8 | MCS0 的边（144.8） | 64 × 256 次，16.4 ms | 够不到（129.8）/ 2.0 ms / — | 够不到（136.6）/ 1.02 ms / — |
| B 11ac 20M × 8 | 解码器上限（124.1） | 64 × 1 次，70 µs | 257 / 9 / 266 µs | 34 / 4 / **38 µs** |
| A 11be 80M | MCS0 的边（150.3） | 64 × 64 次，111 ms | 够不到（138.9）/ 13.9 ms / — | 够不到（145.6）/ 6.96 ms / — |
| A 11be 80M | 解码器上限（129.3） | 64 × 1 次，1.75 ms | 871 / 218 / 1090 µs | 437 / 109 / **546 µs** |

- **两级扫描补不了 MCS0 的边**：宽扫的子阵比整阵少 20·log10(N/m) 的 EIRP（m = 8 / 16 少 14.7 / 9.0 dB），重复训练场每翻一倍只拿回约 1.5 dB，到 256 次也差 4.7–15.0 dB。动手前按这个量级估过，算出来一样。
- **有余量的地方它省时间**：解码器上限的距离上 m = 16 比平扫快 1.8–3.2 倍（宽扫一段场就够）；m = 8 的宽扫要重复 4–32 次，反而不快。
- **边缘上真正贵的是挑扇区**：第二级只扫 4 个窄扇区时，在 MCS0 的边上 64 次重复是 1.74 ms（B 11be × 4），比平扫快 16 倍。所以缩短边缘训练要的是一个不靠 60 GHz SNR 的粗方向（例如 MLO 的 sub-7 链路测到达角），而不是更宽的波束；sub-7 测向精度没有出处，记 ROADMAP B。

## 6. 斜视（示例 10 §5）

移相器只在载频对准，偏离载频的音波束偏开。45° 扫描、按占用的音平均 / 最差的音的阵列增益损失：

| 占用带宽 | N = 16 | N = 64 |
|---|---|---|
| 320 MHz（11be 80M × 4） | 0.00 / 0.00 dB | 0.02 / 0.05 dB |
| 640 MHz（× 8） | 0.00 / 0.01 | 0.06 / 0.19 |
| 2.56 GHz（× 32） | 0.06 / 0.19 | **0.98 / 3.36** |

只有 2.56 GHz 配大阵列时斜视才算数；真时延没有这项。每音均衡把形状拿掉，剩下的是 SNR 损失。

## 6b. 802.11ay 两种波形在同一套阵列上（示例 10 §3d，2026-11-16）
- `arraylink.ay_array_budget`：同一个阵列、同一个前端实例、同一条解码器上限规则。底板不是解析和，而是在每个单元的回退上真跑过校准的链上读时域；门限：SC 是本库实测的（spec_sources#33 的码，`data/spec/ay_per_thresholds.yaml`，2026-11-16 起），OFDM 来自 `assumed.ay_sensitivity`。
- 结论与数在 `cairn/ay.md` §8。要点：顶到 EIRP 上限时 PA 直流功率与工作点几乎无关（class-B 的 PAE 规律）；SC 回退小，省下的是单元与移相器，代价是接收增益。

## 7. 没建的（ROADMAP B）

- 时域里逐单元 PA 的非线性在远场合成（现在 PA 只按回退进底板；N 颗同样的 PA 在束向上的失真与单颗相同，单元误差会让各 PA 的驱动不同，没算）。
- 多径下的扇区选择（平坦信道、视距）；对端的扇区扫描（双向各一次）只算一个方向。
- 氧吸收的原文（ITU-R P.676，按载频）：现在是 15 dB/km 的估算，按载频不变。
- 粗方向来自 sub-7 链路（MLO 测到达角）的训练；重复训练场的跨重复相干累加要的相位稳定（只当上界）。两级扫描（§5c）已建：边上补不了距离。
- 功率列里逐单元的 LNA / 混频、分路 / 合路插损（与单元件口径一致，不计）。
