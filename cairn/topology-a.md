# 拓扑 A：IF 延伸（里程碑 1 / A1）

## 1. 模型与插入点（`src/mmw60/ifext.py`）

芯片 = wifitrx 自己的收发机，K = 1，按 wifitrx 自己的配方建（`handoff/runner.build_calibrated_trx`：随机化损伤、它自己的 PA 与频综），
再跑它交付的校准序列（`run_full_cal`，14 步）。芯片的 RF 输出在 6 GHz 段的一个信道上，这就是中频：

    芯片 TX（不改） → 间级电平 → IF 带通（纹波、群时延） → 固定 LO 混频（f_LO = f_c − f_IF，带相噪） → 60 GHz PA

接收侧镜像。`IfExtenderTx` / `IfExtenderRx` 是 wifitrx `TxChain` / `RxChain` 的子类，60 GHz 级加在父类 `__call__` 之后（接收侧之前）：
**级关掉时逐位等于父类**（`tests/test_ifext.py::test_law2_stage_off_*`）。因为它们仍是链，wifitrx 的回环和校准代码不用改就能跑在上面。

- 60 GHz PA、LO 相噪剖面、EIRP 限值是共享 `Frontend60` 里的同一批对象（铁律 2）。晶振、信道、接收机也与拓扑 B 相同。
- 60 GHz PA 是测量的 60 GHz CMOS PA（Asada，EuMC 2011；`assumed.pa60_surveyed_pick`）：Psat 14.6 dBm、增益 23.2 dB、P1dB 10.0 dBm、峰值 PAE 16.3 %，Rapp p = 1.286（P1dB 比 Psat 低 4.6 dB）。AM/PM 原文没给，仍用 11ad 的。
  回退从 Psat 7.5 dB（`derived.pa60_obo_at_evm_limit_db`，算得 7.457），Pout 7.1 dBm，在 P1dB 之下 2.9 dB；隔离 EVM −21.1 dB（示例 09）。
  规则是 `assumed.pa60_operating_rule`：PA 单独在类 OFDM 包络上 EVM 刚到 −21 dB 的那个回退。−21 dB 是 802.11ad 16-QAM 的 TX EVM 限值，也是 60 GHz 发射机 `pa60.wu_isscc2015` 额定输出的口径。
  （2026-11-13 回退改成 7.5 dB 之前：沿用 Liu 的从 Psat 8 dB，Pout 6.6 dBm，P1dB 之下 3.4 dB，隔离 EVM −22.1 dB。`config.tgad_em_pa(cfg)` 那一行仍用 Liu 的 8 dB，Liu 自己的预设也没动。）
  （2026-11-12 预设换成测量的 PA 之前是 11ad 评估方法学的 Rapp：Psat 15 dBm（assumed）、增益 20 dB、峰值 PAE 20 %、p = 0.81（P1dB 比 Psat 低 9.5 dB），Pout 7.0 dBm，隔离 EVM −18.1 dB。`config.tgad_em_pa(cfg)` 换回它，作灵敏度行。）
- 基带转换器、IQ、LO 泄漏、RX DC 是芯片自己的（wifitrx 的，已校准），所以拓扑 A 的预设里前端那几个开关是关的。
- **接收前端**（2026-11-14，`assumed.ifext_rx_front60`）：共享前端的 `rx_front` 是 60 GHz 前端（`sourced`，如 `config.surveyed_frontend`）时，芯片前串一级固定增益的 60 GHz LNA / 混频：取它的最高增益档（增益、NF、IIP3），芯片自己的梯子在后面做 AGC。灵敏度用 Friis 级联 NF（`LinkSim._rx_nf_db`）；时域里这一级加输入参考的 kT·(F1 − 1/G1)，加上芯片在其后加的 kT·F2，总和正好是 Friis。预设的 WiFi 7 梯子就是芯片那颗 sub-7 梯子的替身，不在芯片前再放一份，所以预设的数不动。60 GHz 观测回环从混频器进，不过 LNA。
  11be 80 MHz、MCS 0 的灵敏度：预设 −92.52 dBm（NF 3.50 dB）；查到的前端 −89.92 dBm（级联 NF 6.10 dB：LNA 6.1 dB、增益 27 dB，芯片 3.5 dB 只加 0.0025 dB）。差 2.60 dB，与拓扑 B 同一换法相同（示例 08 §5）。SNR 10 dB 处两者的链路 EVM −9.31 / −9.38 dB：LNA 的噪声在时域里按级联 NF 加进去了。无噪声的链路 EVM −20.46 → −20.27 dB：芯片输入高了 27 dB，AGC 从第 0 档退到第 4 档。**更正**：此前这一级是单位增益、不加噪声，换上查到的前端时拓扑 A 的灵敏度不动（差 0.00 dB），拓扑 B 动 2.6 dB（ROADMAP C9 原第三条）。
- `ifext.chip` 另有一档 `frontend`：把共享前端自己在 1× 的链当芯片（PA 旁路、未校准，像拓扑 B）。`ideal()` 选它，铁律 2 的理想对比靠它。
- 只有拓扑 A 有的项：芯片校准后的残差（实测）、芯片自己的 LO、IF 滤波器、镜像带噪声。只有拓扑 B 有的项：未校准的基带 IQ 镜像、ENOB(fs_eff) 的转换器、LO 泄漏与 RX DC。同台表逐行标出。

## 2. 频率规划（示例 06 §1；位置而已，本引擎不背书杂散电平）

载频 60.48 GHz = IF 6.48 GHz + 固定 LO 54.00 GHz；×3 方案 PLL 在 18.0 GHz，×4 在 13.5 GHz，×9 在 6.0 GHz（`assumed.ifext_lo_scheme`；×9 是 2026-11-14 为 pllsim 行加的，见 §5）。
镜像边带 47.52 GHz、LO 馈通 54.00 GHz，都在 57–71 GHz 之外。换信道靠芯片在 6 GHz 段内调 IF，固定 LO 不动。
相噪直接给在 LO 输出端（1 极 1 零剖面），所以 N 只进规划和 PLL 频率，不改相噪数字。
pllsim 剖面（`model: profile`）放在 LO 频率 54.0 GHz 上，不在载频上（`Mmw60Config.lo_hz`、`Lo60.at`）；剖面经过 pllsim 的 ×N 块时，N 要等于 `lo.scheme` 的倍频数，否则报错。
**更正（2026-11-14）**：此前 `make_profile` 对两条拓扑都传载频，拓扑 A 配 pllsim 剖面时用的是 60.48 GHz 的 ×10 文件，IPN 比 54.0 GHz 的 ×9 文件高 0.95 dB（理想规律 20·log10(60.48/54) = 0.98 dB）。预设与已有的表都用 1 极 1 零剖面，没有一行受影响（指纹逐位不变）。

IF 带通：Chebyshev-I 5 阶、0.5 dB 纹波、通带 1.2 GHz（`assumed.ifext_filter`）。80 MHz 信道离通带中心 −45 MHz 时带内纹波 0.22 dB、群时延展宽 61 ps；
挪到通带边缘是 0.50 dB、1231 ps。它是线性的，接收机的信道估计把它均衡掉：链路 EVM 只动 ≤ 0.02 dB（2026-11-13 回退改成 7.5 dB 之前 ≤ 0.01 dB；换 PA 之前 ≤ 0.02 dB）。
接收侧镜像抑制 30 dB 时噪声系数恶化 0.004 dB，10 dB 时 0.41 dB。

## 3. 校准真跑（铁律 4；示例 06 §2）

同一颗未校准的芯片，同一套序列，两种观测：芯片自己的耦合器；60 GHz 观测回环（第二级 PA 后的耦合器，同一个固定 LO 下变频回芯片 RX，LO 相噪相消）。

| 步骤 | 芯片耦合器 | 60 GHz 观测回环 |
|---|---|---|
| tx / rx LPF 角频、RX DC | ok（0.18 % / 0.06 %，−69.1 dBFS） | 相同 |
| AGC 落点误差 | 0.41 dB | 0.46 dB |
| TX LO 泄漏（包络 / 回环） | −66.0 / −66.1 dBc | −64.5 / −63.5 dBc |
| RX IIP2 | 74.5 dBm | 74.5 dBm |
| TX IQ / RX IQ（irr_min） | 55.67 / 55.56 dB | **47.48 / 47.18 dB，degraded** |
| 群时延 | −30.0 ps | −28.1 ps |
| DPD（拟合后 EVM） | −41.8 dB | −21.5 dB |
| 最终回环 EVM | −41.6 dB | −22.7 dB |
| 校准后：芯片输出 / 60 GHz PA 输出的 TX EVM | −41.44 / −23.06 dB | **−14.18** / −22.24 dB |

未校准时 60 GHz PA 输出的 TX EVM 是 −20.46 dB。结论：**整套序列不要照搬到 60 GHz 观测回环上**。OBO 7.5 dB 的第二级 PA 在观测通路里，
IQ 校准把它的失真当成镜像去修（IRR 掉 8.2 / 8.4 dB），芯片自己输出端的 TX EVM 从 −41.44 掉到 −14.18 dB：校正量里混进了第二级的失真，芯片单独看是被校坏了。
60 GHz PA 输出端的 TX EVM 是 −22.24 dB，比在芯片耦合器上校的 −23.06 dB 还差 0.82 dB。
所以本库的做法是：全套校准在芯片自己的耦合器上跑；只有 DPD 一步可以选在 60 GHz 观测回环上重训，并且和芯片上原有的预失真器比过，留好的。
（2026-11-12 预设换成测量的 PA 之前：未校准 −18.26 dB；IRR 掉 18–20 dB（37.9 / 36.0 dB）；芯片输出掉到 −11.9 dB；60 GHz PA 输出 −21.4 对 −20.0 dB，好 1.4 dB，当时归给 DPD 一步。结论没变：PA 压缩变硬后观测通路里的失真小了，IQ 校准仍被带偏。）
（2026-11-13 回退从 8 dB 改成 7.5 dB 之前：观测回环一列 LO 泄漏 −64.8 / −63.8 dBc，IIP2 70.3 dBm，IRR 48.35 / 47.92 dB（掉 7.3 / 7.6 dB），群时延 −29.0 ps，DPD −23.1 dB，最终回环 −24.3 dB；
未校准 −21.13 dB；芯片输出掉到 −15.82 dB；60 GHz PA 输出 −24.34 对 −24.08 dB，在观测回环上校的好 0.26 dB。
这一条结论变了：原来在 60 GHz PA 输出端还略好，现在差 0.82 dB，整套搬过去连 60 GHz 输出端也不划算。IQ 校准被带偏这一条没变。）

- **更正（2026-11-11，wifitrx@7b8d08e）**：本节原先写 DPD 一行是 **−14.1 dB、发散**，最终回环 −14.9 dB，60 GHz PA 输出的 TX EVM −14.7 dB，并说“wifitrx 的序列照样把发散的预失真器写进去”。
  那是 wifitrx 0.7.38 及以前的行为（无条件写入第 2 轮）。0.7.39 起它的 DPD 步在观测通路上读“不加预失真”和每一轮，写入最好的（wifi_trx_cal B40，本库在 #5 上报告的），所以这三格变成 −21.7 / −22.1 / −21.4 dB。IQ 校准被第二级失真带偏这一条没有变。

- **观测回环在 8 dB 回退上值 +1.63 dB，10–12 dB 值 7.45–7.71 dB，14 / 16 dB 回落到 5.45 / 2.71 dB，6 dB 上值 0。**
  这张表扫的是固定的 6 … 16 dB，不随预设变，2026-11-13 数字没动。8 dB 是那之前的预设；现在的预设 7.5 dB 不在网格上，它上面观测回环值多少没有量。
  回落是因为芯片上的预失真在大回退下自己就到 −36.37 / −39.70 dB，而写入的那一个停在 −41.82 / −42.41 dB。
  （2026-11-12 预设换成测量的 PA 之前：8 dB 上 +1.2 dB，10 dB 以上 6–10 dB，16 dB 仍有 +8.5 dB，没有回落。）
- **间接学习（ILA）在这颗 PA 上越迭代越差**，每个回退都是：三轮里第 1 轮最好，第 3 轮最差。靠近饱和时第二轮就把第一轮的成果丢掉（8 dB：−25.69 → −16.66 → −8.65），6 dB 上连第 1 轮（−16.27）都不如不加（−18.41）。
  测量的 PA（Rapp p = 1.286，P1dB 比 Psat 低 4.6 dB）压缩比旧的 11ad Rapp 硬，现象照旧：预失真要把增益补回小信号值，峰值驱动超出 PA 给得出的输出，下一遍在训练范围之外拟合。
  （换 PA 之前这里写的是：这颗 Rapp（平滑度 0.81，P1dB 比 Psat 低 9.5 dB）压缩得很软，8 dB 上 −20.6 → −14.1 → +1.4。）
  PA_DPD 自己的 `ILAPredistorter` 在裸的 11ad Rapp 上同样（OBO 8 dB：1 / 2 / 4 次迭代 −37.4 / −18.0 / +6.2 dB；换 PA 之前量的，测量的 PA 上没有重跑）。两颗 PA 上都这样，所以是算法在这类 PA 上的性质。
- 谁来挑：wifitrx 0.7.39 起，`calibrate_dpd` 自己在观测通路上读“不加预失真”和每一轮并写入最好的（或不写入）。本库（`IfExtender.train_dpd_mmw`）只做它做不了的一步：
  它不知道这颗芯片上已经有一个在自己耦合器上训好的预失真器，也不知道预失真会改变级联的输出功率。所以把它留下的那个放回目标输出功率，和芯片上原有的在同一观测通路上比，留好的。
  `assumed.ifext_dpd_max_iterations`（2）现在是交给它试的轮数。
- **更正（2026-11-11）**：本节第一版只跑 wifitrx 的默认 2 次迭代，写的是“8 dB 回退上观测回环值 0 dB、ILA 发散”，并把原因归给 PA。验收 PA_DPD#4 时用它自己的 ILA 扫迭代次数才发现原因是迭代。
  第二版本库自己循环 1 … N 次迭代、各训一次再比；上游在 0.7.39 把“留最好的一轮”收进 DPD 步之后，这层循环去掉了（同日，重新 pin 到 7b8d08e）。表里中间一栏从“放回同一输出功率后读的 1 / 2 / 3 次迭代”换成了上游在训练驱动下自己的读数，数字差 ≤ 0.9 dB，结论没变。
- 预设仍是 `dpd_observation: chip`：60 GHz 观测回环是额外的硬件（耦合器加一条下变频通路），同台表的拓扑 A 行不带它。带上它在 8 dB 回退上 TX EVM 从 −23.9 到 −25.5 dB，链路 EVM 仍被相噪（−25 dB）和 PA（8 dB 上隔离 −22.1 dB）压着（换 PA 之前是 −19.9 → −21.0 dB）。
  现在的预设 7.5 dB 上 PA 隔离 EVM 是 −21.1 dB，压得更紧；那里带不带观测回环没有量（2026-11-13）。

| 18.9 dBm（9.1 dB，增益码上限） | −29.0 | −17.7 / MCS4 | −20.0 / MCS6 | −21.4 / MCS6 | −22.1 / MCS7 | 555 mW |

芯片的输出要先衰减 28.5 dB 才到第二级的驱动电平（2026-11-13 回退改成 7.5 dB 之前 29.1 dB；换 PA 之前 24.1 dB）。这张表扫的是第二级 6 / 8 / 10 / 12 dB，数字没动。第二级 6–8 dB 回退上芯片 PA 的回退几乎不进链路 EVM（一列之内差 ≤ 1.0 dB）；
10–12 dB 上增益码上限那一行（芯片残差 −29.0 dB）比出厂增益那一行差 1.6 / 2.0 dB，10 dB 处少一档（MCS6 对 MCS7）：第二级干净了，芯片自己的残差开始露出来。
（2026-11-12 预设换成测量的 PA 之前：每一列之内差 ≤ 1.1 dB，结论是芯片 PA 的回退几乎不进链路 EVM。）
它花的是直流功率：**芯片 PA 作驱动级耗 202–555 mW，是 60 GHz PA（约 75 mW）的 3–7 倍**（2026-11-13 回退改成 7.5 dB 之前 60 GHz PA 约 70 mW，3–8 倍；换 PA 之前 63 mW，3–9 倍）。
60 GHz PA 的直流功率由示例 04 §4 的 pa 列乘速率得到（2870 pJ/bit × 26 Mb/s、518 × 144）。
链路 EVM 由第二级回退定，出厂增益那一行 6 → 8 → 10 → 12 dB 依次好 2.7 / 2.0 / 1.1 dB，到 12 dB 处（−24.1 dB）逼近相噪（−25 dB）。

## 6b. 芯片 PA 旁路（示例 06 §5b；`ifext.chip_pa_bypass`，2026-11-14）

IF 从芯片的混频器输出取，芯片 PA 断电、不计功耗（`assumed.ifext_chip_pa_bypass`；预设不开）。wifitrx 的交付序列在这条链上真跑（铁律 4）：
- 校准耦合器跟着移到 PA 前，衰减减去实测的 PA 大信号增益（25.6 dB），芯片接收机看到交付序列调好的电平；
- DPD 步不跑：芯片上没有要线性化的 PA；
- tx_power 步只建表：没有输出可设，增益码留在出厂值。

| 步（11be 80 MHz，芯片 seed 5） | 读数 | 芯片 PA 在 | 旁路 |
|---|---|---|---|
| tx_iq | irr_min | 55.67 dB | 62.21 dB |
| rx_iq | irr_min | 55.56 dB | 54.44 dB |
| rx_iip2 | iip2 | 74.50 dBm | **42.93 dBm（判失败）** |
| tx_lo_leak_loopback | 泄漏 | −66.06 dBc | −66.27 dBc |
| final_loopback_evm | 总 / TX / RX | −43.49 / −43.17 / −40.39 dB | −43.92 / −45.18 / −40.41 dB |

- TX IQ 好 6.5 dB：PA 的 AM/PM 不再混进 IQ 估计。
- **IIP2 修调失败**：wifitrx 序列里 IIP2 一步的耦合器衰减是 `max(主路衰减 − 10, 30)` dB，30 dB 是绝对下限（按 PA 输出电平的双音定的，防接收机压缩）。耦合器在 PA 前时主路衰减只有 14.4 dB，下限顶住，双音到接收机低了约 25.6 dB，修调搜索不收敛。本库不改 vendor，照实记下（ROADMAP A1）。链路仿真里没有阻塞信号，IIP2 不进链路 EVM。
- 级间从 −28.50 dB 变成 −2.65 dB，仍是衰减，不需要另加驱动级；60 GHz PA 输出同是 7.1 dBm。
- 链路：底板 −19.6 dB 不动，时域 −20.4 → −20.3 dB，解码器上限同是 MCS6、324 Mb/s。pJ/bit 2143 → 1236，芯片 PA 一项原是 907。
- 320 MHz 与拓扑 B 的 80 MHz × 4 对比在同台表（`comparison-table.md` §2、§2b）。

另一种做法没有建：带着 PA 按交付方式校准，链路上再旁路。那样 IIP2 步照常，但 IQ 估计里有 PA 的失真，残差要在旁路模式下另量。

## 7. CFO（铁律 3；示例 06 §6；`impairments/cfo.py::MloCfo`）

40 ppm × 60.48 GHz = 2.419 MHz = 31 个子载波，芯片的 L-STF 只到 ±625 kHz。接法：MLO 的 sub-7 链路（5.5 GHz）用 L-STF + L-LTF 估出自己的 CFO（220 kHz），
乘 f_c / f_sub7 = 11.0 预补偿 60 GHz 链路；残差 = sub-7 估计误差 × 11.0，再交给芯片自己的估计器。估计是真跑的（前导 + 偏移 + 噪声过本库的估计器），每包一次。

| sub-7 SNR | sub-7 估计误差 rms | 60 GHz 残差 rms / 最大 | 最大残差（子载波） |
|---|---|---|---|
| 5 dB | 4.5 kHz | 49.7 / 148.9 kHz | 1.91 |
| 10 dB | 2.3 kHz | 25.0 / 69.2 kHz | 0.89 |
| 20 dB（预设） | 0.68 kHz | 7.4 / 24.0 kHz | 0.31 |
| 30 dB | 0.21 kHz | 2.3 / 8.0 kHz | 0.10 |

链路 EVM：预补偿开 −20.44 dB；关掉 +4.10 dB（失败）；ppm = 0 时 −20.39 dB（2026-11-13 回退改成 7.5 dB 之前 −21.04 / +7.12 / −21.00；换 PA 之前是 −18.31 / +4.33 / −18.27）。ppm 为零时整项（偏移、估计、预补偿）关掉，信号逐位原样返回。
前提是每台设备的 sub-7 LO、芯片 IF LO 和 60 GHz 固定 LO 同源一颗晶振（`assumed.mlo_common_reference`）；不成立时预补偿失效。

## 8. 与拓扑 B 同台（`comparison-table.md` §2）

同样 320 MHz、同一颗 60 GHz PA、同一回退，解码器上限 A 是 MCS6、1297 Mb/s，B 是 MCS5、1153 Mb/s（示例 04 §4b）。
每比特：拓扑 A（11be 320 MHz，K = 1）765 pJ/bit，拓扑 B（80 MHz × 4）487 pJ/bit；芯片 PA 旁路后 A 是 538（§6b）。
A 每比特贵 1.6 倍，多出来的是芯片 PA（作驱动级）和每端两个频综。A 的带宽止于芯片的 320 MHz；B 还能到 640 MHz（1729 Mb/s、474 pJ/bit）。
A 换来的是芯片不用改，以及已校准的基带（芯片 IRR 55 dB；B 未校准时镜像项 −31 … −12 dB）。PA 隔离 EVM 现在是 −21.1 dB，B 在 80 MHz × 4 上的镜像项（−24.7 dB）与它同量级，
所以这点好处在 320 MHz 上就显出来：底板 A −19.5 dB 对 B −18.5 dB，解码器上限高一档。
（2026-11-12 预设换成测量的 PA 之前：两者都是 MCS4、865 Mb/s，A 1128 pJ/bit、B 628 pJ/bit，A 每比特是 B 的 1.8 倍；PA 隔离 EVM −18.1 dB 把这点好处盖住，只在 B 的宽带格里才显出来；B 的 640 MHz 是 467 pJ/bit。）
（2026-11-13 回退改成 7.5 dB 之前：A 762、B 483 pJ/bit，B 的 640 MHz 472 pJ/bit；PA 隔离 EVM −22.1 dB，底板 A −20.2 对 B −19.0 dB。两边的上限和结论没变。）

解码器上限用 PER 复核（示例 06 §8）：MCS6 预测 19.48 dB、实测 18.61 dB；MCS7 预测 25.05、实测 23.08。偏保守 0.87 / 1.97 dB。
拓扑 B 的 K = 4（示例 05，上限 MCS5）在上限那一档几乎正好：MCS5 17.61 / 17.62；高一档 MCS6 20.88 / 20.00，偏保守 0.88 dB。
（2026-11-13 回退改成 7.5 dB 之前：A 的 MCS6 18.90 / 18.05、MCS7 23.25 / 21.34，偏保守 0.85 / 1.91 dB；B 的 MCS5 17.22 / 17.14、MCS6 20.10 / 20.11，两档都几乎正好。B 高一档那一格现在偏保守了。）
（换 PA 之前 A 的上限是 MCS4，MCS4 12.71 / 11.85、MCS5 18.98 / 18.03，偏保守 0.9–1.0 dB，与当时拓扑 B 的 K = 4 一样。）
