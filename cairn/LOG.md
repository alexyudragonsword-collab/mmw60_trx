## 2026-11-12 · 60 GHz PA 对照原文：偏的是形状不是 Psat（feat/pa60-sources，示例 09）

- 读了三篇东工大 65 nm 60 GHz CMOS PA 的原文：Asada（EuMC 2011）Psat 14.6 / P1dB 10.0 dBm / 增益 23.2 dB / PAE 16.3 %；Wu（A-SSCC 2012）13.2 / 10.2 dBm、15.0 %；Li（ELEX 2011）11.7 / 9.4 dBm、14.3 %。Asada 那篇 Table I 汇编 14 颗：Psat 8.0–19.9（中位 12.4）、Psat − P1dB 1.0–9.0（中位 3.3）dB。
- **被推翻的判断**（C9 里我写的）：“Asada 2011 的发射机 Psat 6.5 dBm，本库假设的 15 dBm 大很多”。6.5 dBm 是收发机的发射输出，没有 PA 级；同组独立 PA 是 14.6 dBm，15 dBm 在范围里。
- 偏的是形状：11ad 那颗 Rapp（p = 0.81）P1dB 在 Psat 下 9.5 dB。用 Asada 的 4.6 dB 算出 p = 1.286（`derived`，测试复算）。从 Psat 回退 8 dB 时，预设在 P1dB 之上 1.5 dB，测量形状在之下 3.4 dB。
- PA 单独 EVM，从 Psat 回退 4 / 6 / 8 / 10 / 12 dB：预设 −12.4 / −15.2 / −18.1 / −21.1 / −24.1，测量 −14.3 / −18.1 / −22.1 / −26.2 / −30.5。从 P1dB 算：−26.5 / −29.7 / −32.9 / −36.1 / −39.4 对 −23.3 / −27.5 / −31.9 / −36.4 / −41.1。“回退 8 dB”和 11ad 形状是配套的。
- 同台表 11be 80 MHz（解码器上限），预设对测量：拓扑 A MCS4 → 6、216 → 324 Mb/s、3153 → 2130 pJ/bit；K = 1 4 → 6、1204 → 830；K = 4 4 → 5、865 → 1153、628 → 483；K = 8 不动（4，467 / 472），限制项从 PA 变成 IQ 镜像；K = 16 / 32 不动。
- DPD（K = 8，TX 单独，回退 6 / 8 / 10 dB）：预设拿回 0.0 / 0.8 / 4.5 dB，测量形状 0.0 / 2.0 / 2.6 dB。C8 里“预设回退上 DPD 几乎没收益”的原因是形状。
- 效率：P1dB 处 Asada 测 7.9 %（B 类折 9.6、A 类 5.7），Li 测 12.0 %（B 类 11.0）。预设峰值 PAE 20 % 高于测量 14.3–16.3 %。
- 没出处：AM/PM（去掉它 EVM 好 0.2–0.5 / 0.3–1.7 dB）。Wu 的 QPSK EVM 被测试链限住，不能用。
- 预设没换，指纹不变。换不换、回退改从哪里算，记在 ROADMAP C10，等用户定。
- 读法上的教训：上一轮把“收发机的发射输出”当成“PA”比，是又一次把两个不同的量并排。

## 2026-11-11 · 隔离实验：示例 07 的“代价”是在 DPD 的崖上读的；按回退读是 0.5–2.3 dB（feat/pa-memory-isolation）

- 起因：对方在 wifi_trx_cal#5 上复现不出“PA 抽头隔 8–16 个样本最糟、差 4–6 dB”，否定了发射基带低通的解释。ROADMAP C8 第一条的隔离实验这一轮做掉。
- 隔离（临时脚本，K = 8 抽头隔 16 个样本、预设回退 8 dB）：把 IQ 失配、转换器量化、LO 泄漏全关掉，EVM 差 6.1 → 5.5 dB，不是它们。同一 K 下只改抽头间隔（K = 32：2 / 4 / 8 / 16 / 32 / 64 个样本）代价 1.0 / −0.1 / 2.2 / 4.4 / 2.9 / 0.5 dB，干净前端下反而全是 4–7 dB，读数很不规则。
- 细扫回退（K = 8，DPD 后 TX EVM，随信号缩放 / 按秒固定取好的间隔）：7.0 dB −21.7 / −19.9；7.5 −26.1 / −20.4；8.0 −27.5 / −21.5；8.5 −28.2 / −24.0；9.0 −28.4 / −25.0；10.0 −28.5 / −26.9；12.0 −28.6 / −28.1。
  K = 32：7.0 −21.2 / −21.5；7.5 −25.5 / −23.3；8.0 −25.8 / −25.2；8.5 −27.6 / −26.3；9.0 −28.3 / −27.2；10.0 −28.6 / −28.2；12.0 −28.4 / −29.0。
- **查到的原因**：预设的 8 dB 回退在 DPD 的崖上。随信号缩放的那颗 PA 的崖在 7.0–7.5 dB（半个 dB 内 EVM 变 4.4 dB），按秒固定的晚 1–2 dB、坡更缓。单点上的 EVM 差是两条崖的间距。
  按同一个 EVM 比各自要退多少：K = 8 目标 −25 / −27 dB 是 7.4 / 7.8 对 9.0 / 10.1（代价 1.6 / 2.3 dB）；K = 32 是 7.4 / 8.3 对 7.9 / 8.9（0.5 / 0.6 dB）。K = 32 粗格点上抽头 12.5 / 3.125 / 0.78 ns：0.1 / 0.8 / −0.2 dB（−25）与 0.4 / 0.7 / 0.1 dB（−27）。

## 2026-11-06 · 里程碑 0：引擎对上 Liu 2025 Fig. 4（ccr-65a5163d-bbo5rb，0.0.1）

- **验收（PER = 1e-2 处 SNR，dB；原文读图 MCS0 4.2 / MCS1 7.5 / MCS4 19.7(8×) 19.0(16×)）**：字面读法（LOS/散射信道 + OBO 自 Psat）K=8 MCS0/1/4 = 6.59 / 9.83 / 21.00，K=16 = 6.68 / 9.80 / 21.83，差 +1.3 … +2.8 dB，**超过 1 dB**；
  flat 信道 K=8 = 5.35 / 8.59 / 20.42，K=16 = 5.18 / 8.82 / 19.84（差 +1.15 / +1.09 / +0.72；+0.98 / +1.32 / +0.84）；无损伤 K=8 = 6.10 / 9.00 / 17.00。K = 4 三组全 PER = 1 ✓。示例 00 全量 1582 s、01 1222 s（4 核）。

- 建库：vendored wifitrx@cc06b9ac 整包 verbatim；upclocking = 基准数字学 + fs_eff；自建 VHT 编解码（PER）、Rapp、1 极 1 零相噪、L-STF 粗估计。68 项测试，CI 五个作业。
- **解码器与并集界**：K = 8 flat MCS0，genie CSI、不跟踪时 PER 1e-2 在 1.5–2 dB（并集界 2.0 dB）；加 4 导频逐符号 CPE → 4.4 dB；加 L-LTF 估计（平滑 3 音）→ 4.9 dB；不平滑 → 6.0 dB；平滑 9 音 → 4.1 dB。
- **被推翻的判断 1**：原文"refrained from using estimation and compensation algorithms for CFO"按字面不可能——CFO 全关时 K = 4 / 8 / 16 在 SNR 20 dB 全部 PER = 1（示例 00 诊断行）；原文 V-B 的 4.7 论证以 L-STF 自相关估计器在跑为前提，示例 00 按此配置。
- **被推翻的判断 2**：CR 信道先取 15 ns rms 纯 Rayleigh 指数 PDP → K = 16 的 50 ns GI 外能量 −14 dB，EVM 底板 −14 dB，与 Fig. 4 "16× 不比 8× 差"矛盾；改 7 ns（GI 外 −31 dB）并加 LOS/散射 10 dB。即便如此，K = 8 的 LOS/散射信道仍比 flat 贵约 2 dB（MCS0 6.0 vs 4.1–5.0；MCS4 ideal 17.0 vs 15.1，80 包粗扫），原文曲线的陡度说明其信道是 AWGN 样的。
- **被推翻的判断 3**：OBO 8 dB 相对 Psat 用 11ad EM 的 CMOS Rapp（p = 0.81）等于平均功率在 P1dB 之上 1.5 dB，孤立 EVM −17 dB；以为要改成相对 P1dB 才对得上——全量跑出来 P1dB 口径 MCS4 16.39 / 16.04 dB，比原文**好** 3 dB，过度修正；而 flat 信道 + 字面 OBO 的灵敏度行 19.67 dB 与原文 19.7 差 0.03 dB。于是第三组改为 flat + 字面 OBO，P1dB 只留灵敏度行（17.27）。
- **被推翻的判断 4**：以为 16× 会像原文一样在 MCS4 比 8× 好——字面组 16× 反而差 0.8 dB（21.83 vs 21.00）：50 ns GI 外的散射尾 + 5 MHz 音距上的 3 音平滑偏差。
- **新发现**：示例 01 的整数子载波模糊解算让 K = 4 在 2.35 子载波 CFO 下工作：MCS0 6.00 / MCS1 9.21 / MCS4 22.00 dB，只比 K = 8 差 0.6 / 0.6 / 1.0 dB——门槛是估计器的，不是波形的。
