## 4. 发现（2026-11-15 按刊出版重写；更正前的版本在本节末尾）

1. **原文的 CFO 句子与它自己的论证矛盾，刊出版照旧**：刊出版写 “refrained from using estimation and compensation algorithms for CFO and used phase tracking only on the receiving end”（arXiv 是 “for CFO and PN”），同一段仍用 L-STF 自相关的捕获范围推出 K > 4.7；ideal 组的 4× 也是 PER = 1，说明那条门槛在两组里都起作用。全关时 K = 8 / 16 也整包 ICI（示例 00 诊断行 PER = 1）。只用 L-LTF 要 K ≥ 18.8（`upclocking.md` §2）。
2. **MCS4 的平台是现在最大的出入**：原文有损伤的 MCS4 到 31 dB 仍停在 PER 0.105（8×）/ 0.053（16×），本库每一组都在 17.0 … 22.1 dB 到 1e-2。候选（都没查，不调参数）：
   - PA：原文的 modified Rapp 引 [15] IEEE 802.15-06-0477（802.15.3c 的射频损伤模型），本库用的是 TGad 评估方法学的参数；OBO 8 dB 的参考点也没说；
     更正前第 3 条的前半句（11ad EM 的 Rapp 在 OBO 8 dB 下孤立 EVM −17 dB，16-QAM 3/4 到不了 1e-2）与这个平台方向一致；本库的字面组却在 21.8 dB 到了 1e-2，所以要看的是两边 PA 失真进链路的方式（OBO 参考点、AM/PM、逐包驱动），不只是参数；
   - 信道：本库敏感度行里纯 Rayleigh 的 MCS4 在 26 dB 仍是 PER 0.21，与原文 8× 在 25 dB 的 0.18 同量级——逐包衰落的 CR 信道能给出这种平台；但原文 MCS0 / 1 的有损伤曲线 1 → 1e-2 只用 2 dB，纯 Rayleigh 下不会这么陡；
   - 原文的 ideal MCS4（19.0 / 19.7）也比本库的 ideal（16.7 / 17.1）差 2–3 dB，而 MCS0 / 1 的 ideal 反过来原文好 1.6–2.2 dB：原文那边有一项只在高阶调制上要价、相噪与 PA 关掉也还在的东西（信道或接收机），这更像是信道 / 接收机，而不只是 PA。
3. **接收机**：MCS0 / 1 上原文夹在本库两档接收机之间（flat：里程碑 0 的 +0.5 … +0.7 dB，改进的 −2.1 … −2.5 dB），与更正前的判断方向相同，量变小了。
4. **示例 01**：整数子载波模糊解开后 K = 4 工作（MCS0 6.0 / MCS1 9.2 / MCS4 22.0 dB）——原文的门槛是估计器的性质，不是波形的。
5. **16× 在 MCS4 比 8× 好**：原文有损伤的平台 0.053 对 0.105，ideal 19.0 对 19.7；本库 flat 组 20.27 对 20.64，方向一致。字面组（22.14 对 21.82）反过来，原因同更正前第 6 条（50 ns 的 GI 与 7 ns rms 散射尾）。

**被推翻的判断（2026-11-15，刊出版）**
- 更正前第 3 条“原文 MCS4 在 19–19.7 dB 工作，说明其 PA 在 OBO 8 dB 下温和得多（参数不同或 OBO 相对 P1dB）”：那是 ideal 曲线（没有 PA）。原文有损伤的 MCS4 根本到不了 1e-2，它的损伤在 MCS4 上比本库的狠，不是温和。
- 里程碑 0 的“flat 组与 Fig. 4 MCS4 只差 0.03 dB，所以原文是近 AWGN 信道 + 字面 OBO”（`cairn/LOG.md` 2026-11-06）：比的是 ideal 曲线，0.03 dB 是巧合。
- 更正前第 2 条“信道近 AWGN、50 ns 外无能量”：依据的陡度在有损伤组的 MCS0 / 1 上仍成立，但 MCS4 的平台和 ideal 组 MCS4 的 2–3 dB 让“近 AWGN”不再站得住，降为候选之一。

更正前的发现（2026-11-11 版，对的是 v1 那一组，留作记录）：

1. **原文的 CFO 句子与它自己的论证矛盾**：§V-A 说没做 CFO 估计补偿，§V-B 的"K > 4.7"却是 L-STF 自相关捕获范围的结论；全关时 K = 8 / 16 也整包 ICI（示例 00 诊断行 PER = 1）。只用 L-LTF 要 K ≥ 18.8（`upclocking.md` §2）。
2. **信道**：原文曲线 3 dB 内从 1 到 1e-3，且 16× 处处不比 8× 差 → 信道近 AWGN、50 ns 外无能量。任何"像样的"CR 散射模型都会把 K = 8 的曲线右移 ~2 dB（LOS/散射 10 dB + 7 ns）或更多（纯 Rayleigh：曲线拉平）。
3. **PA**：11ad EM 的 CMOS Rapp 在 OBO 8 dB（相对 Psat）下孤立 EVM −17 dB，16-QAM 3/4 到不了 1e-2；原文 MCS4 在 19–19.7 dB 工作，说明其 PA 在"OBO 8 dB"下温和得多——要么参数不同，要么 OBO 相对 P1dB。
4. **接收机**：解码器压在并集界上；逐符号导频 CPE 的尾部贵 2.5 dB（MCS0）；这解释了为什么本库 flat 信道下 MCS0 在 5.25 dB 而不是理论的 2 dB，与原文的 4.2 dB 差 +1.05 dB——剩下的差是接收机实现（原文的信道估计 / 跟踪细节未知）。C1 / C2 做完后这一条有了实测：换成跨符号 CPE 合并 + 自动平滑，flat MCS0 到 2.54 dB，比原文好 1.66 dB。原文的接收机比本库里程碑 0 的好、比改进的差。
5. **示例 01**：整数子载波模糊解开后 K = 4 工作（MCS0 6.0 / MCS1 9.2 / MCS4 22.0 dB，比 K = 8 差 0.6 / 0.6 / 1.0 dB）——原文的门槛是估计器的性质，不是波形的。
6. **16× 在 MCS4 不比 8× 好（字面组 22.14 对 21.82，区间重叠）而原文好 0.7 dB**：K = 16 的 GI 只有 50 ns，7 ns rms 的散射尾（−31 dB）加上 5 MHz 音距上 3 音平滑的偏差，吃掉相噪 ICI 减小带来的好处；flat 组里两者 20.64 / 20.27，方向与原文一致、差 0.4 dB（原文 0.7）。
