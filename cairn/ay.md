# 里程碑 3：802.11ay 两种波形（当前真相）

> 范围、取舍与已经量到的。ROADMAP 里程碑 3 记没做的；数字原值在 `cairn/LOG.md`。

## 1. 范围（用户 2026-11-16 定）

- ay 不是第三条拓扑：拓扑 B 的硬件（零中频链、同一前端实例）配第三、四种波形 `ay_ofdm` / `ay_sc`。
- 数字（EDMG OFDM / SC 单信道数字学、MCS 表、DMG / EDMG 的 TX EVM 限值、灵敏度表）只从 spec_sources 进来（铁律 5）。已发 spec_sources#29，本库是发起方，合并后由本库验收并关。2026-11-16 已回（spec_sources#30，pin `3123b65`；键见 `cairn/spec-sources.md`），EDMG 灵敏度没有出处。
- 第一轮只做 EVM 口径（不做编码 PER），只做单信道（不做 2 / 3 / 4 信道绑定）。
- 数字到之前先建与数字无关的部分；`config.WAVEFORMS_BUILT` 不含 ay，`LinkSim` 照样拒绝（`tests/test_laws.py::test_law1_waveform_enum_is_complete_and_ay_refuses`）。

## 2. 骨架（`src/mmw60/ay/`，2026-11-16）

每个模块都把数字学当参数，测试用的是合成数字学（2 的幂、1 GS/s），`tests/test_ay_skeleton.py`。

| 模块 | 内容 | 测试守的 |
|---|---|---|
| `golay.py` | 由延迟向量 D 与权向量 W 递推出 Golay 互补对（802.11ad 写 Ga / Gb 的同一形式；用哪组 D / W 是规范数字） | 任意 D 排列、W ∈ {±1, ±j} 下互补；非法 D / W 报错 |
| `sc.py` | 单载波块：[G \| d₀ \| G \| d₁ \| … \| G]，窗口 [d_b \| G] 前面的 G 就是循环前缀；可选逐样本旋转 e^{jrn}（π/2-BPSK 一族），要求 r·block 是 2π 的整数倍，否则拒绝；互补对各带一段循环前缀做信道估计（DMG CEF 的原理，不是它的布局）；ZF / 去偏 MMSE 频域均衡；用尾部已知 G 逐块跟公共相位 | 信道不长于 G 时估计与 ZF 都精确到数值精度，长于 G 时有块间干扰；flat 信道上 MMSE 读出 SNR（±0.3 dB）且无偏；相位漂移被尾 G 跟住 |
| `ofdm.py` | 任意子载波排布（FFT 点数、CP、采样率、数据 / 导频的有符号索引、导频值）；训练符号估信道、ZF、导频去公共相位；`receive(h=)` 给定信道（PA 隔离读法） | 多径不长于 CP 时精确；逐符号随机公共相位被导频去掉 |
| `papr.py` | 理想插值 / 抽取、根升余弦成形与匹配滤波、PAPR CCDF、`obo_for_evm`（共享 PA 上 EVM 到目标所需的回退） | 往返透明；多音 OFDM 的 1e-3 处 PAPR 是高斯包络的 8.39 dB（±0.3）；回退差约等于 PAPR 差 |

CFO：重复一段长 L 的序列，`rx.cfo.stf_coarse_cfo` 以 L 为滞后估计，范围 ±fs/(2L)，越界按 fs/L 混叠（测试守）。ay 的 L-STF 用哪段序列、重复几次是规范数字。

## 3. 在合成数字学上量到的（不是 ay 的结论）

根升余弦滚降 0.25、4 倍过采样，PAPR（dB，1e-3 / 1e-4）：

| 波形 | 1e-3 | 1e-4 |
|---|---|---|
| OFDM（337 音，QPSK） | 8.36 | 9.50 |
| SC BPSK | 4.87 | 5.03 |
| SC π/2-BPSK | 1.92 | 2.02 |
| SC QPSK | 4.24 | 4.67 |
| SC 16-QAM | 5.47 | 6.23 |
| SC 64-QAM | 5.77 | 6.37 |

EVM 到目标所需的输出回退（dB，从 Psat 算；PA 隔离读法：两边都只去一个复增益，OFDM 不带训练场过 PA）：

| PA | 波形 | −15 dB | −20 dB | −25 dB |
|---|---|---|---|---|
| 预设（测量的形状，p = 1.286） | SC π/2-BPSK / QPSK / 16-QAM / 64-QAM | 0 / 0 / 1.26 / 1.47 | 0 / 0.36 / 3.27 / 3.63 | 1.27 / 2.49 / 5.47 / 5.89 |
| | OFDM QPSK / 16-QAM / 64-QAM | 3.37 / 3.34 / 3.37 | 6.08 / 5.96 / 6.05 | 8.64 / 8.44 / 8.58 |
| TGad EM（p = 0.81） | SC π/2-BPSK / QPSK / 16-QAM / 64-QAM | 0 / 0 / 1.82 / 2.05 | 0 / 0.62 / 4.77 / 5.20 | 2.03 / 3.63 / 7.86 / 8.35 |
| | OFDM QPSK / 16-QAM / 64-QAM | 4.46 / 4.42 / 4.46 | 8.10 / 7.98 / 8.07 | 11.46 / 11.28 / 11.41 |

- 同一星座（16-QAM）SC 比 OFDM 少退 2.7 dB（预设 PA）/ 3.2 dB（TGad EM），与 1e-3 处的 PAPR 差 2.9 dB 一致。ROADMAP 原写的"SC 的 PAPR 低 3–4 dB"对 QPSK / π/2-BPSK 成立（4.1 / 6.4 dB），对 16 / 64-QAM 是 2.6–2.9 dB——验收线"≥ 3 dB"要写明星座与滚降。
- OFDM 的回退与星座无关（包络是高斯的）；SC 的回退随星座涨。所以 SC 换来的 EIRP 是"低阶星座上多、高阶上少"，要和它丢掉的频谱效率一起算，这一步等 ay 的 MCS 表。
- 0 dB 的格是"在饱和处就已经达标"（π/2-BPSK 几乎恒包络，压缩只是一个公共增益）。
- 滚降不在标准里（只有频谱模板），建 ay 行时它是 `assumed` 条目，带灵敏度行。

### 坑：训练场的峰值也过 PA（contains: 训练场 PAPR、全 1 训练）
- 全 1 的训练值在时域是一个冲激，PAPR = 使用音数（169 音即 22 dB），过 PA 被削，信道估计整体歪掉：同一回退上读数差 10 dB（2026-11-16 第一次量时踩到）。
- 换成随机 ±1 之后，OFDM 到 −20 dB 的回退随训练值的种子差 1.5 dB（8.45 对 6.97）：训练符号自己的峰值在削。所以 PA 隔离读法给 `receive(h=)` 不带训练场；真实帧里训练场（ay 的 CEF）怎么过 PA 是链路口径要单独算的一项——11ad / ay 的前导是单载波 Golay 序列，PAPR 低，所以这一项在真实帧里应当小，等数字到了实测。

## 4. 第一段接线（2026-11-16，feat/ay-wiring；示例 15）

**接法**：`config.WAVEFORMS_BUILT` 四种都在；`LinkSim(cfg)` 遇到 `ay_ofdm` / `ay_sc` 交给 `sim/ay_link.AyLinkSim`。前端模型、前端实例、信道、CFO、相噪、SNR 口径与 be 的链路共用，只换帧和接收机。
- 只在拓扑 B、EDMG 信道中心、K = 1 上；配置拒绝其余组合。数字学、MCS、EVM 限值、速率都从 spec 读（`ay/edmg.py`）。
- 预设 `config.ay_60ghz(waveform, mcs)` 建在 `zero_if_60ghz(k=1)` 上，前端设置与 be 预设逐字段相同。
- 两种波形跑在同一条链上（`assumed.ay_chain_rate`）：OFDM 2.64 GS/s × 2 = SC 1.76 Gchip/s × 3 = 5.28 GS/s，滤波器按 2.16 GHz 信道间隔建。
- 帧（`assumed.ay_preamble`）：STF 是 128 点 Golay × 16，CEF 是一对 Golay，各带一段 GI 长的循环前缀，后面是载荷。SC 用 RRC 0.25 成形（`assumed.ay_sc_pulse`）。
- 接收机（`assumed.ay_receiver`）：
  - STF 用 lag 128 自相关估 CFO（范围 ±fs/256）；
  - 用 CEF 那一对估信道，冲激响应截在 GI 内；
  - SC 用 MMSE 频域均衡，相位在每块前后两段 GI 之间线性插值；
  - OFDM 用 ZF，逐符号用 16 个导频去公共相位。
- 载荷不编码（`assumed.ay_evm_payload`）。
- SNR 定义：SC 按每码片、OFDM 按每有效子载波的 in-band SNR，与 be 同一口径。理想链在 20 dB 上读 −19.7 / −19.2 dB。

**示例 15 量到的**（信道 2，普通 GI，预设前端，flat 信道，不加噪声）：
- **PAPR**（载荷，1e-3）：OFDM 8.29–8.45 dB。SC 在滚降 0.25 时，π/2-BPSK 1.89、π/2-QPSK 4.16、π/2-16-QAM 5.49、π/2-64-QAM 5.71 dB。低阶差 ≥ 3 dB，验收线成立。
- **单开各项**（预设回退 7.5 dB，SC 载荷 64-QAM / OFDM 16-QAM）：

  | 损伤 | SC | OFDM |
  |---|---|---|
  | 理想链 | −49.9 | −36.9 |
  | PA | −28.4 | −21.7 |
  | 相噪 | −27.5（每块只取一个相位：−25.1） | −27.7 |
  | 转换器 | −41.8 | −35.6 |
  | 未校准的 IQ | −5.1 | −4.0 |
  | 未校准的 TX LO 泄漏，不加 CFO | 无影响 | 无影响 |
  | 未校准的 TX LO 泄漏 + CFO | −24.5 | −32.1 |

  IQ 失配在 be 的 2.56 GHz 行上一样大（原始链 −4.6 dB），要靠校准。
  TX LO 泄漏只有带着 CFO 才进来：接收端在安静前导上量 DC 并减掉，没有 CFO 时减得干净；有 CFO 时泄漏旋转着到，前导上平均掉，CFO 校正后又回到 DC。OFDM 那里是空的 DC 音，SC 那里是每个码片。
- **全开的底板与合规上限**（预设回退）：
  - 原始链：SC −8.1 … −8.2、OFDM −6.4 … −6.6 dB。上限 SC MCS2、OFDM 无。
  - 把 IQ 与 LO 泄漏当作校准掉：SC −24.3 … −25.5、OFDM −20.9 … −21.0 dB。上限 SC MCS16（π/2-16-QAM 7/8，5.39 Gb/s）、OFDM MCS15（16-QAM 7/8，5.11 Gb/s）。
- **同调制、同码率、各按自己的 EVM 限值**：SC 少退 0.36–0.68 dB（16-QAM 1/2 … 7/8、64-QAM 1/2），速率高 5.6 %（1.54 对 1.46 G 符号/s）。64-QAM 5/8 两边持平；3/4 起 SC 要多退 4.15 dB 或够不到。SC 的限值比 OFDM 严 3–4 dB（同为 16-QAM 1/2，−19 对 −15 dB），2.8 dB 的 PAPR 优势大部分被它吃掉。
- **每个 PA 输出功率上的最好速率**（单天线，EVM 口径）：回退 ≤ 8 dB（Pout ≥ 6.6 dBm）时 SC 高。例如 13.6 dBm 上 2.70 对 0.91 Gb/s，8.6 dBm 上 5.39 对 4.74 Gb/s。回退 ≥ 9 dB 时 OFDM 高（6.57–7.66 对 5.78–6.93 Gb/s）。原因是 SC 的底板停在约 −27 dB（相噪），够不到 64-QAM 13/16、7/8 的 −28 / −29 dB；OFDM 的 −25 / −27 dB 够得到。
- **一句话**：单天线、同一颗 PA，要输出功率（距离）就用 SC，要峰值速率就用 OFDM。SC 的回退优势在同调制同码率上只剩 0.4–0.7 dB，因为标准对 SC 的 EVM 要求更严。

**被推翻的判断**（`cairn/LOG.md` 2026-11-16）：
1. ROADMAP 原写的"SC 用回退换来的 EIRP，够不够抵掉丢掉的频谱效率"有前提错误。同调制同码率时 EDMG SC 的速率比 OFDM 高 5.6 %，丢的不是频谱效率。真正的代价是 SC 更严的 EVM 限值，以及更低的相噪底板。
2. 铁律 3 原写的"ay 靠 5.16 MHz SCS 本身"不成立。2.42 MHz 是 0.47 个子载波，不估计时两种波形都坏（EVM > −5 dB）；接住它的是 STF。

### 坑：OFDM 的理想链比 SC 差（contains: 理想链底板、GI）
- 理想链（无任何损伤）上 OFDM 只到 −35.7 … −37.9 dB，SC 到 −40 … −50 dB，随 GI 不单调。原因没查。离最严的限值（SC −29、OFDM −27 dB）还有 8 dB 以上，不影响上面的结论。

## 5. 第二段 2a：在 ay 的链上真跑校准（2026-11-16，feat/ay-stage2；示例 15 §7–§8）

**接法**：
- `calcheck.run_cal_ay(fe, cfg)` 在 ay 的链（2.16 GHz、5.28 GS/s）上跑 wifitrx 的序列（铁律 4）。
- 序列要的评分波形是 `assumed.ay_cal_probe`：11be 80 MHz × 22，过采样 3，占 1.71 GHz。2.16 GHz 配 5.28 GS/s 不是整数倍，所以借一个落在链通带里的标准波形。
- 链自己的步骤按链的参数走：LPF 角频按 `fc_nominal_hz`，IQ 的 FIR 按 `bandwidth_hz`。探针只用于快照、终检和 DPD 训练。
- 先在探针上把 PA 修到预设回退（Psat − 7.5 dB）再跑，不带 DPD，和 be 的行一样。
- `LinkSim(cfg, frontend=fe, chains=run.chains[:2])` 在校准过的链上跑 ay 波形。只校准一次；换回退时只重修驱动，和实际用法一致。
  （更正，第二段 2b：换回退时只重修驱动不行，TX LO 泄漏的抵消只对校准时的增益状态成立，见下面的坑。扫回退时每个点各校一次；同台表只在预设回退上读，一次就够。）

**校准过的链上**（示例 15 §8，预设回退，flat，不加噪声）：

- **合规上限不变**：SC MCS16（5.39 Gb/s），OFDM MCS15（5.11 Gb/s）。
- **同调制同码率的回退**（每个回退点各跑一次校准）：
  - SC 少退 0.36–0.55 dB（16-QAM 1/2 … 7/8），64-QAM 1/2 少退 0.24 dB，64-QAM 5/8 多退 0.33 dB；（2026-11-17 wifitrx 0.7.41 + `set_gain` 之前是 0.14–0.32 / 0.07 / 0.55 dB：那时 SC 的校准链带着泄漏残差，见 §9a。）
  - SC 的 64-QAM 3/4 以上在回退 15 dB 内够不到；OFDM 64-QAM 7/8 在 12.88 dB 够到。
  - **更正（2026-11-16，第二段 2b）**：这一条最初（#51）读的是只在预设回退校准一次、换回退只重修驱动的链，得 SC 少退 0.01–0.15 dB、64-QAM 5/8 多退 0.34 dB、OFDM 64-QAM 7/8 够不到。那是假象，见下面的坑。
- **SC 在校准过的链上多出来的损失**：每个回退点各校一次后，SC 比“当作校准掉”多 0.2–0.8 dB（回退 5 / 7.5 / 10 / 12.5 / 15 dB 时 +0.45 / +0.38 / +0.21 / +0.44 / +0.78），OFDM 在 ±0.07 dB 内。原因没完全找到（2026-11-17 更正：找到了，见 §9a 与下面的坑——泄漏步的偏置不在 FFT 网格上，wifitrx B42；本库校准后直接给 VGA 赋值，B43。wifitrx 0.7.41 + `set_gain` 后 7.5 / 15 dB 上只剩 0.12 / 0.45 dB，是 IQ 残差）：
  - 已排除：带着 CFO 进来的残余 LO 泄漏（关掉 CFO，SC 校准链 −24.28、当作校准掉 −24.84 dB，差不变）；探针外推带边的 IQ 校正（滚降 0.10 / 0.25 / 0.40，带边 ±0.97 / ±1.10 / ±1.23 GHz，差 0.31 / 0.38 / 0.40 dB）。

  （ROADMAP 里程碑 3）

### 坑：LO 泄漏的校准只在它那个增益状态成立（contains: 增益状态、dc_pre、单次校准、换回退）
- wifitrx 的 TX LO 泄漏步骤算出一个数字预抵消 `dc_pre`，它对的是校准时的 VGA。换回退要改 VGA（预设 7.5 dB 时 −3.2 dB，15 dB 时 −11.4 dB），抵消就对不上了，泄漏回来。
- 接收端在安静前导上量 DC 并减掉，所以没有 CFO 时看不出来；带着 CFO，泄漏旋转着到、在前导上平均掉，CFO 校正后又是 DC，压在每个 SC 码片上。
- 数（示例 15 §8 那一行，π/2-16-QAM）：在 7.5 dB 校准、跑在 15 dB，带 CFO −27.01 dB、不带 −26.95 dB；在 15 dB 重新校准 −26.75 dB（2026-11-17 起；之前 −16.56 / −26.09 / −26.41，见下面的更正）。
- 所以在校准过的链上扫回退，每个点都要重新跑序列（真芯片按增益档各校一次）。（2026-11-17 起不再必须；示例 15 §8 仍每点各校一次，读法不改。）
- **更正（2026-11-17，wifi_trx_cal#6）**：坑在本库自己。`dc_pre` 在数字域、在增益码与 VGA 之前，它要抵消的泄漏在调制器、在两者之后；本库校准后为回退改 VGA 用的是直接赋值，等于把 `dc_pre` 跟着放大、泄漏没变。wifitrx 0.7.41 加了 `TxChain.set_gain`，按增益变化反缩 `dc_pre`；`Frontend60.set_vga_for_obo` 改用它之后，一次校准在别的回退上照样成立（上面的数：−27.01 对重新校准的 −26.75 dB）。守着的测试改成 `test_the_tx_lo_leak_null_survives_a_vga_change_through_set_gain`：`set_gain` 时与重新校准差不到 1 dB，把修 VGA 换回直接赋值时差 6 dB 以上。

| 15 dB | OFDM | −36.64 | −46.00 | −47.58 | −46.78 | −37.41 | −47.24 |

RX DC 单开等于底板，没有贡献。直接读数：`dc_pre` 之后剩的泄漏 −42.1 / −42.9 dBc（不加 `dc_pre` 是 −23.9 / −16.4）；TX 镜像抑制在 0.5 / 0.86 / 1.0 / 1.1 GHz 是 52.0 / 53.7 / 40.9 / 27.1 dB（7.5 dB）、45.1 / 43.0 / 43.3 / 28.3 dB（15 dB），未校正时 13.0 / 7.7 / 6.1 / 5.1 dB。

**读到的**：
- 7.5 dB 时，SC 多出来的损失主要是 TX 泄漏残差：序列的 `dc_pre` 把 −24 dBc 的泄漏压到 −42 dBc，剩下的这一点（**更正**：−42 dBc 是经 DAC 零输入读的封底值，真实残差更大，见上）。把 `dc_pre` 解成恰好抵消，缺口从 0.38 缩到 0.13 dB（−24.47 → −24.72，“当作校准掉”是 −24.85），剩下的是 IQ 残差；15 dB 时从 0.79 缩到 0.42 dB。带不带 CFO 都一样（§8b 那两行）。
- 单开时（其他损伤全关），残差只在有 CFO 时起作用：没有 CFO 时，接收端在安静前导上量到的直流正好就是它，减得干干净净。可在整条链上，不带 CFO 它也有代价（PA 关掉也有），所以它是和另一项损伤一起起作用的，那一项还没定位（2026-11-17 定位：链路校准后直接给 VGA 赋值，见上）。
- 单开时它在 SC 上读出来比它自己的功率大：7.5 dB 时大 7.6 dB，15 dB 时只大 1.1 dB。其中 1.8 dB（7.5 dB 时）是前导去直流造成的：泄漏在前导上随 CFO 旋转，只被部分平均掉，减去的是一个错的常数。其余的还没找到；已排除 SC 的相位跟踪（关掉、按块都一样）和信道估计截窗（关掉一样）。
- 15 dB 时三项差不多大：TX IQ −40.2、泄漏 −41.8、RX IQ −41.8 dB。
- OFDM 的泄漏落在三个空着的 DC 子载波上；它的 IQ 残差比 SC 大（−38.0 对 −43.9 dB），但 OFDM 的底板高，看不出来。
- 核对：三项按功率加回“当作校准掉”的读数，SC 是 −24.32 / −26.70 dB，校准链是 −24.47 / −26.41 dB，差在 0.3 dB 内。缺口就是这三项，没有别的。
- 带边：探针只到 ±0.86 GHz，1.1 GHz 处的镜像抑制只剩 27–28 dB。但 SC 在那里只有滚降的尾巴，与 §5 “滚降 0.10–0.40 时差不变”一致。

**更正**：§5 说“TX 侧的校准状态约 0.2 dB、RX LPF 码约 0.13 dB”，那是把状态逐项搬到干净链上量的。现在在校准链本身上逐项隔离：7.5 dB 时主要是 TX 泄漏残差，15 dB 时 TX IQ、泄漏、RX IQ 三项相当。§5 那条“关掉 CFO 差不变”仍然成立：整条链上残差不带 CFO 也有代价。

### 坑：隔离时先关 PA 再建链，读出来的泄漏是假的（contains: VGA、隔离读法、dc_pre）
- `LinkSim` 建链时按 PA 输出修 VGA。PA 一关，VGA 就跑到别处；`dc_pre` 在 VGA 之前、泄漏在 VGA 之后，抵消对不上，泄漏单开读成 −22 dB（真值 −34.5 dB）。
- 做法：PA 开着建链，修好 VGA 以后再关 PA（示例 15 §8b 的 `stripped`）。这和 §5 那个增益状态的坑是同一回事。

### 9b. 多径（示例 15 §10，feat/ay-multipath）
**先修了一个 bug**：SC 的 MMSE 把噪声方差当成 1/SNR，可信道估计带着链的增益（mean|h|² ≈ 0.064），正则化大了约 16 倍。flat 信道上 |H| 处处一样，这只是整体缩放，去偏之后没有影响；多径下均衡器被扭曲，CR 信道、带内 SNR 12 dB 时白丢约 1.4 dB，比 ZF 还差。现在按估计自己的标度给（mean|h|²/SNR）。之前发布的 ay 数全是 flat 或不加噪声，一个都不动。测试守着：多径下 MMSE 要好过 ZF，flat 上两者一样（`test_the_sc_mmse_reads_the_noise_on_the_channel_estimates_scale`）。新配置项 `ay.sc_equalizer`（`mmse` / `zf`）作灵敏度行。

**读到的**：
- 预设的 CR 替身（rms 7 ns）几乎都在 36.4 ns 的 GI 以内：不加噪声的底板只差 0.2–0.5 dB，12 dB 上两者都差 0.8–0.9 dB（多径下每包的信道有起伏）。

- 这些读数换算到距离：门限（`assumed.ay_sensitivity`）是 AWGN 的；在 CR 替身下，同样的 EVM 要多 0.8–0.9 dB 的 SNR，距离约短 10 %。没有改 §9 的距离表：那一节是 flat、视距。

### 9c. ay 自己的扇区扫描：能扫多远（示例 10 §4d，feat/ay-sector-sweep）
**接法**（新 assumed `ay_sector_sweep`）：每个扇区发一个 SSW 帧，用 DMG 控制 PHY（MCS 0，SC 加 Golay 扩频）发，远端要解出最好那个扇区的帧。门限按 `ay_sensitivity` 同一条规则从 MCS 0 的灵敏度反推：−11.48 dB（1.76 GHz 带内，扩频增益在里面）。注意 MCS 0 的判据是 256 octets 上 PER 5 %，其他档是 4096 octets 上 1 %。发端扫描时远端只用一个单元，收端扫描在选好的发端波束后面，和 be 行靠 MLO 触发的训练（示例 10 §4）同样的设定。阵列与单元输出用 §8 的（预设回退）。一次扫描两种 ay 波形共用。

### 9d. 编码 PER：DMG / EDMG 的码与实测门限（`ay/coding.py`，feat/ay-coded → feat/ay-33-keys）
- **已建**：`phy.ldpc.qc_code` 能从任意基矩阵与提升因子构造准循环码（802.11 的码改走它，边数组逐位相同；DMG / EDMG 的是 16 列、z = 42）。SC 载荷装整数个码字，不够一个码字的比特用随机填充，接收端丢掉。接收端从均衡后的码片求 max-log LLR，不做逐码片加权：SC 的 MMSE 让每个码片 SINR 相同，归一化 min-sum 又对 LLR 的整体缩放不敏感。任一码字的任一信息比特错就算丢包。`AyLinkSim.transmit(rng, bits=)` 接收载荷比特（只对 SC）。
- **替身验证**：用 802.11 的 648 码（码率 1/2）、π/2-QPSK、行为模型的理想链：不加噪声时零错，−3 dB 全丢，6 dB 全对；把 LLR 的符号翻过来测试就变红（`test_the_coded_sc_path_with_an_80211_code_standing_in`）。替身码的 PER 曲线不打印：它不是 EDMG 的码，打出来容易被当成 EDMG 的数。
- **码（2026-11-16，spec_sources#33，铁律 5）**：`coding.dmg_code` 从 `dmg.ldpc_matrices` 提升四个码率（1/2、5/8、3/4、13/16，672 位，z = 42）；DMG 的 7/8 是 13/16 码字不发前 48 个校验位（`dmg.ldpc_r7_8_punctured`，624 / 546，`PuncturedCode`：收端在那 48 位填零 LLR）。`coding.edmg_code` 在 7/8 用 EDMG 自己的 672 位码（`edmg.ldpc_672_r7_8`，588 位信息；大多数格是两个移位单位阵之和，`qc_code` 为此接受一格多个移位，相等的移位在 GF(2) 上相消，拒收）。spec_sources 的交叉核对在本库复现：EDMG 7/8 的校验阵就是 DMG 3/4 的第 1+3、2+4 块行之和，逐位相同。每个码编出来校验子为零、干净码字解得回（`test_the_dmg_and_edmg_codes_are_spec_sources_matrices_and_agree_with_each_other`）。`PendingSpec` 删掉了。

  - **本库的 OFDM 接收机比 SC 差 0.6–1.0 dB**（同调制同码率）。在理想链、13 dB 上拆开（16-QAM 3/4）：EVM 比 SNR 差多少，SC 0.34 dB、OFDM 0.76 dB；换成无噪声的信道估计后，SC 0.04 dB、OFDM 0.31 dB。所以信道估计噪声两边都吃（SC 0.30、OFDM 0.45 dB），OFDM 另有约 0.3 dB：最可能是每个符号只用 16 个导频估公共相位（13 dB 时这份噪声约 0.25 dB，SC 用每块 64 码片的 GI 跟踪）。排除了：CFO 估计（开关一样，估计的抖动 4 kHz）、载荷与前导的功率差（0.00 dB）。OFDM 的估计更噪，部分是因为本库的 Golay CEF 在 2.64 GHz 上发（`assumed.ay_preamble`），只有约 69 % 的能量落在用到的子载波上。
  - 这些是本库接收机的性质，不是规范数。改进的办法（跨符号的 CPE 平滑，像 be 行的 C1；CEF 按 DMG 的混合速率前导在 1.76 GHz 上发）记在 ROADMAP。
**DCM 档的编码载荷与实测门限（2026-11-17，spec_sources#43，feat/ay-ofdm-dcm）**：
- `ay/dcm.py`：`edmg.ofdm_modulation_mapping` 的 DCM BPSK / DCM QPSK，放在第 k 与第 P(k) = k + N_SD/2 号数据子载波上（静态配对，所有模式必须支持；动态配对由接收方反馈，没建）。接收端对一对子载波的 2^(2 n_bpsc) 个假设做联合 max-log，两个子载波噪声不同时也按各自的权重合并。测试按规范的公式逐点核对映射，并验证擦掉每对里任一个子载波后比特仍全对（变异检查：矩阵写错、只用一个子载波解，测试都变红）。
- 不传比特时（只读 EVM 的载荷）每个子载波仍各自随机取 QPSK / 16-QAM 点，与原来逐位相同；子载波上的星座本来就是这两个，EVM 读数不变。
- 门限（`--waveform ay_ofdm --only 1 … 10`）：

- **读到的**：
  - 孪生规则在 DCM 档上也偏乐观（0–1.44 dB），与 16-QAM / 64-QAM 档一致；OFDM 现在每档都是本库实测，孪生规则只剩 SC MCS 1。
  - flat 信道上 DCM 的两个矩阵都是酉的，等价于每个子载波上的普通 BPSK / QPSK，所以“OFDM − SC”就是本库两种接收机之差。它**随码率降低而变大**：码率 7/8 时 0.4–0.7 dB，1/2 时 1.5–1.7 dB；16-QAM / 64-QAM 档是 0.57–0.97 dB。
  - 一半来自 EVM：门限链上 4.7 dB 时 EVM 比 SNR 多丢 OFDM 1.0–1.15 / SC 0.2–0.25 dB（差 0.8–0.9 dB），13 dB 时 0.78–0.83 / 0.30–0.32 dB（差 0.5 dB）。剩下的推测是 OFDM 的信道估计误差在一个包里对每个子载波不变（一个固定的旋转和缩放），LDPC 在低码率时对这种不随机的误差更敏感；没有单独验证。记进 ROADMAP 的接收机一项。

- **没建**：扰码与填充 / 缩短规则（载荷是随机比特，扰码不改 PER；PSDU 按整数个码字发）、重复 2 的编码步骤（MCS 1；说明里替换哪 168 位有歧义，已请 spec_sources#43 贴原句）、1344 位长码字（`edmg.ldpc_1344_lifting`）、DCM 的动态配对、16 / 64-QAM 的符号内交织（置换不公开，`assumed.ay_ofdm_tone_order`）。
- **测量里的一个坑**（`tools/measure_ay_thresholds.py`）：`per_sweep` 在第一个 200 包零错的点停扫。MCS 18 第一次在 15.5 dB 零错停了，续跑到 3000 包反而有 48 错（PER 1.6 %，200 包零错的概率约 4 %），交叉点落在最后一点之外，记成 “never”。工具改成：没有交叉、最后一点又有错时，从最后一点下两格换种子重扫（最多 3 次）。`per_sweep` 本身不改：be 的门限表也用它。
- **第二个坑**（同一工具，2026-11-17）：OFDM MCS 11 第一次的区间宽 0.81 dB（[9.42, 10.23]）。9.5 dB 上 29/3000 正卡在 1 %，交叉点两侧只有它和 9 dB 跑满，上界要靠只跑了 200 包的 10 dB（2 错）外推。工具改成区间宽于 0.5 dB 时两侧邻点也续跑：重测后 8.5 dB 60/90、10 dB 8/3000，门限仍是 9.49，区间 [9.42, 9.60]。SC 各档的区间都窄于 0.5 dB，这条规则对它们不触发，表不用重量。
