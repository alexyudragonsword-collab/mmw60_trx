# 里程碑 3：802.11ay 两种波形（当前真相）

> 范围、取舍与已经量到的。ROADMAP 里程碑 3 记没做的；数字原值在 `cairn/LOG.md`。

## 1. 范围（用户 2026-11-16 定）

- ay 不是第三条拓扑：拓扑 B 的硬件（零中频链、同一前端实例）配第三、四种波形 `ay_ofdm` / `ay_sc`。
- 数字（EDMG OFDM / SC 单信道数字学、MCS 表、DMG / EDMG 的 TX EVM 限值、灵敏度表）只从 spec_sources 进来（铁律 5）。已发 spec_sources#29，本库是发起方，合并后由本库验收并关。2026-11-16 已回（spec_sources#30，pin `3123b65`；键见 `cairn/spec-sources.md`），EDMG 灵敏度没有出处。
- 第一轮只做 EVM 口径（不做编码 PER），只做单信道（不做 2 / 3 / 4 信道绑定）。
- 数字到之前先建与数字无关的部分；`config.WAVEFORMS_BUILT` 不含 ay，`LinkSim` 照样拒绝（`tests/test_laws.py::test_law1_waveform_enum_is_complete_and_ay_refuses`）。

## 2. 骨架（`src/mmw60/ay/`，2026-11-16）

每个模块都把数字学当参数，测试用的是合成数字学（2 的幂、1 GS/s），`tests/test_ay_skeleton.py`。

| 模块 | 内容 | 测试守的 |
|---|---|---|
| `golay.py` | 由延迟向量 D 与权向量 W 递推出 Golay 互补对（802.11ad 写 Ga / Gb 的同一形式；用哪组 D / W 是规范数字） | 任意 D 排列、W ∈ {±1, ±j} 下互补；非法 D / W 报错 |
| `sc.py` | 单载波块：[G \| d₀ \| G \| d₁ \| … \| G]，窗口 [d_b \| G] 前面的 G 就是循环前缀；可选逐样本旋转 e^{jrn}（π/2-BPSK 一族），要求 r·block 是 2π 的整数倍，否则拒绝；互补对各带一段循环前缀做信道估计（DMG CEF 的原理，不是它的布局）；ZF / 去偏 MMSE 频域均衡；用尾部已知 G 逐块跟公共相位 | 信道不长于 G 时估计与 ZF 都精确到数值精度，长于 G 时有块间干扰；flat 信道上 MMSE 读出 SNR（±0.3 dB）且无偏；相位漂移被尾 G 跟住 |
| `ofdm.py` | 任意子载波排布（FFT 点数、CP、采样率、数据 / 导频的有符号索引、导频值）；训练符号估信道、ZF、导频去公共相位；`receive(h=)` 给定信道（PA 隔离读法） | 多径不长于 CP 时精确；逐符号随机公共相位被导频去掉 |
| `papr.py` | 理想插值 / 抽取、根升余弦成形与匹配滤波、PAPR CCDF、`obo_for_evm`（共享 PA 上 EVM 到目标所需的回退） | 往返透明；多音 OFDM 的 1e-3 处 PAPR 是高斯包络的 8.39 dB（±0.3）；回退差约等于 PAPR 差 |

CFO：重复一段长 L 的序列，`rx.cfo.stf_coarse_cfo` 以 L 为滞后估计，范围 ±fs/(2L)，越界按 fs/L 混叠（测试守）。ay 的 L-STF 用哪段序列、重复几次是规范数字。

## 3. 在合成数字学上量到的（不是 ay 的结论）

根升余弦滚降 0.25、4 倍过采样，PAPR（dB，1e-3 / 1e-4）：

| 波形 | 1e-3 | 1e-4 |
|---|---|---|
| OFDM（337 音，QPSK） | 8.36 | 9.50 |
| SC BPSK | 4.87 | 5.03 |
| SC π/2-BPSK | 1.92 | 2.02 |
| SC QPSK | 4.24 | 4.67 |
| SC 16-QAM | 5.47 | 6.23 |
| SC 64-QAM | 5.77 | 6.37 |

EVM 到目标所需的输出回退（dB，从 Psat 算；PA 隔离读法：两边都只去一个复增益，OFDM 不带训练场过 PA）：

| PA | 波形 | −15 dB | −20 dB | −25 dB |
|---|---|---|---|---|
| 预设（测量的形状，p = 1.286） | SC π/2-BPSK / QPSK / 16-QAM / 64-QAM | 0 / 0 / 1.26 / 1.47 | 0 / 0.36 / 3.27 / 3.63 | 1.27 / 2.49 / 5.47 / 5.89 |
| | OFDM QPSK / 16-QAM / 64-QAM | 3.37 / 3.34 / 3.37 | 6.08 / 5.96 / 6.05 | 8.64 / 8.44 / 8.58 |
| TGad EM（p = 0.81） | SC π/2-BPSK / QPSK / 16-QAM / 64-QAM | 0 / 0 / 1.82 / 2.05 | 0 / 0.62 / 4.77 / 5.20 | 2.03 / 3.63 / 7.86 / 8.35 |
| | OFDM QPSK / 16-QAM / 64-QAM | 4.46 / 4.42 / 4.46 | 8.10 / 7.98 / 8.07 | 11.46 / 11.28 / 11.41 |

- 同一星座（16-QAM）SC 比 OFDM 少退 2.7 dB（预设 PA）/ 3.2 dB（TGad EM），与 1e-3 处的 PAPR 差 2.9 dB 一致。ROADMAP 原写的"SC 的 PAPR 低 3–4 dB"对 QPSK / π/2-BPSK 成立（4.1 / 6.4 dB），对 16 / 64-QAM 是 2.6–2.9 dB——验收线"≥ 3 dB"要写明星座与滚降。
- OFDM 的回退与星座无关（包络是高斯的）；SC 的回退随星座涨。所以 SC 换来的 EIRP 是"低阶星座上多、高阶上少"，要和它丢掉的频谱效率一起算，这一步等 ay 的 MCS 表。
- 0 dB 的格是"在饱和处就已经达标"（π/2-BPSK 几乎恒包络，压缩只是一个公共增益）。
- 滚降不在标准里（只有频谱模板），建 ay 行时它是 `assumed` 条目，带灵敏度行。

### 坑：训练场的峰值也过 PA（contains: 训练场 PAPR、全 1 训练）
- 全 1 的训练值在时域是一个冲激，PAPR = 使用音数（169 音即 22 dB），过 PA 被削，信道估计整体歪掉：同一回退上读数差 10 dB（2026-11-16 第一次量时踩到）。
- 换成随机 ±1 之后，OFDM 到 −20 dB 的回退随训练值的种子差 1.5 dB（8.45 对 6.97）：训练符号自己的峰值在削。所以 PA 隔离读法给 `receive(h=)` 不带训练场；真实帧里训练场（ay 的 CEF）怎么过 PA 是链路口径要单独算的一项——11ad / ay 的前导是单载波 Golay 序列，PAPR 低，所以这一项在真实帧里应当小，等数字到了实测。

## 4. 第一段接线（2026-11-16，feat/ay-wiring；示例 15）

**接法**：`config.WAVEFORMS_BUILT` 四种都在；`LinkSim(cfg)` 遇到 `ay_ofdm` / `ay_sc` 交给 `sim/ay_link.AyLinkSim`。前端模型、前端实例、信道、CFO、相噪、SNR 口径与 be 的链路共用，只换帧和接收机。
- 只在拓扑 B、EDMG 信道中心、K = 1 上；配置拒绝其余组合。数字学、MCS、EVM 限值、速率都从 spec 读（`ay/edmg.py`）。
- 预设 `config.ay_60ghz(waveform, mcs)` 建在 `zero_if_60ghz(k=1)` 上，前端设置与 be 预设逐字段相同。
- 两种波形跑在同一条链上（`assumed.ay_chain_rate`）：OFDM 2.64 GS/s × 2 = SC 1.76 Gchip/s × 3 = 5.28 GS/s，滤波器按 2.16 GHz 信道间隔建。
- 帧（`assumed.ay_preamble`）：STF 是 128 点 Golay × 16，CEF 是一对 Golay，各带一段 GI 长的循环前缀，后面是载荷。SC 用 RRC 0.25 成形（`assumed.ay_sc_pulse`）。
- 接收机（`assumed.ay_receiver`）：
  - STF 用 lag 128 自相关估 CFO（范围 ±fs/256）；
  - 用 CEF 那一对估信道，冲激响应截在 GI 内；
  - SC 用 MMSE 频域均衡，相位在每块前后两段 GI 之间线性插值；
  - OFDM 用 ZF，逐符号用 16 个导频去公共相位。
- 载荷不编码（`assumed.ay_evm_payload`）。
- SNR 定义：SC 按每码片、OFDM 按每有效子载波的 in-band SNR，与 be 同一口径。理想链在 20 dB 上读 −19.7 / −19.2 dB。

**示例 15 量到的**（信道 2，普通 GI，预设前端，flat 信道，不加噪声）：
- **PAPR**（载荷，1e-3）：OFDM 8.29–8.45 dB。SC 在滚降 0.25 时，π/2-BPSK 1.89、π/2-QPSK 4.16、π/2-16-QAM 5.49、π/2-64-QAM 5.71 dB。低阶差 ≥ 3 dB，验收线成立。
- **单开各项**（预设回退 7.5 dB，SC 载荷 64-QAM / OFDM 16-QAM）：

  | 损伤 | SC | OFDM |
  |---|---|---|
  | 理想链 | −49.9 | −36.9 |
  | PA | −28.4 | −21.7 |
  | 相噪 | −27.5（每块只取一个相位：−25.1） | −27.7 |
  | 转换器 | −41.8 | −35.6 |
  | 未校准的 IQ | −5.1 | −4.0 |
  | 未校准的 TX LO 泄漏，不加 CFO | 无影响 | 无影响 |
  | 未校准的 TX LO 泄漏 + CFO | −24.5 | −32.1 |

  IQ 失配在 be 的 2.56 GHz 行上一样大（原始链 −4.6 dB），要靠校准。
  TX LO 泄漏只有带着 CFO 才进来：接收端在安静前导上量 DC 并减掉，没有 CFO 时减得干净；有 CFO 时泄漏旋转着到，前导上平均掉，CFO 校正后又回到 DC。OFDM 那里是空的 DC 音，SC 那里是每个码片。
- **全开的底板与合规上限**（预设回退）：
  - 原始链：SC −8.1 … −8.2、OFDM −6.4 … −6.6 dB。上限 SC MCS2、OFDM 无。
  - 把 IQ 与 LO 泄漏当作校准掉：SC −24.3 … −25.5、OFDM −20.9 … −21.0 dB。上限 SC MCS16（π/2-16-QAM 7/8，5.39 Gb/s）、OFDM MCS15（16-QAM 7/8，5.11 Gb/s）。
- **同调制、同码率、各按自己的 EVM 限值**：SC 少退 0.36–0.68 dB（16-QAM 1/2 … 7/8、64-QAM 1/2），速率高 5.6 %（1.54 对 1.46 G 符号/s）。64-QAM 5/8 两边持平；3/4 起 SC 要多退 4.15 dB 或够不到。SC 的限值比 OFDM 严 3–4 dB（同为 16-QAM 1/2，−19 对 −15 dB），2.8 dB 的 PAPR 优势大部分被它吃掉。
- **每个 PA 输出功率上的最好速率**（单天线，EVM 口径）：回退 ≤ 8 dB（Pout ≥ 6.6 dBm）时 SC 高。例如 13.6 dBm 上 2.70 对 0.91 Gb/s，8.6 dBm 上 5.39 对 4.74 Gb/s。回退 ≥ 9 dB 时 OFDM 高（6.57–7.66 对 5.78–6.93 Gb/s）。原因是 SC 的底板停在约 −27 dB（相噪），够不到 64-QAM 13/16、7/8 的 −28 / −29 dB；OFDM 的 −25 / −27 dB 够得到。
- **一句话**：单天线、同一颗 PA，要输出功率（距离）就用 SC，要峰值速率就用 OFDM。SC 的回退优势在同调制同码率上只剩 0.4–0.7 dB，因为标准对 SC 的 EVM 要求更严。

**被推翻的判断**（`cairn/LOG.md` 2026-11-16）：
1. ROADMAP 原写的"SC 用回退换来的 EIRP，够不够抵掉丢掉的频谱效率"有前提错误。同调制同码率时 EDMG SC 的速率比 OFDM 高 5.6 %，丢的不是频谱效率。真正的代价是 SC 更严的 EVM 限值，以及更低的相噪底板。
2. 铁律 3 原写的"ay 靠 5.16 MHz SCS 本身"不成立。2.42 MHz 是 0.47 个子载波，不估计时两种波形都坏（EVM > −5 dB）；接住它的是 STF。

### 坑：OFDM 的理想链比 SC 差（contains: 理想链底板、GI）
- 理想链（无任何损伤）上 OFDM 只到 −35.7 … −37.9 dB，SC 到 −40 … −50 dB，随 GI 不单调。原因没查。离最严的限值（SC −29、OFDM −27 dB）还有 8 dB 以上，不影响上面的结论。
